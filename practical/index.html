HARDCODING PRO · PRACTICALS

Инструкции, Skills и Hooks

Собери AI coding agent с постоянными правилами, настоящим Skill, автоматической защитой и проверяемым E2E.

Результат: continuity, блокировка тестового .env, Skill, config без потерь и Telegram E2E.

1. Три слоя

СлойРоль
InstructionПравила почти всегда
SkillГлубокий workflow по задаче
HookАвтоматическая реакция

2. Настоящий Skill

skills/hardcoding-verify-done/SKILL.md заставляет агента проверять результат по evidence, а не объявлять «готово» по словам.

3. Hooks

SessionStart даёт continuity. PreToolUse блокирует опасные команды и чтение secrets через shell/Read. PostToolUse пишет минимальную телеметрию. Stop может уведомить Telegram.

4. Три runtime

Core: ~/.hardcoding-agent-kit/hooks. Adapter: ZCode → ~/.zcode/cli/config.json; Claude → ~/.claude/settings.json; Codex → ~/.codex/hooks.json.

5. Безопасная установка

Installer читает config, делает timestamped backup и merge-ит только свои hook groups, не удаляя MCP/settings.

6. Secrets локально

python3 ~/.hardcoding-agent-kit/configure_telegram.py

Token вводится скрытым terminal prompt. В обычный чат его не отправляем.

7. Evidence

python3 ~/.hardcoding-agent-kit/hooks/smoke.py
python3 ~/.hardcoding-agent-kit/verify_install.py --runtime zcode
python3 ~/.hardcoding-agent-kit/hooks/test_notify.py
