# Google Sheets: витрина для людей, не сырая сетка

Собрано 11.09.2026 на таблице MPZORRO «Клиенты и очередь» (`/opt/wb-refund-bot/tools/sheets_sync.py`).
Первая версия получила «некрасиво, пиздец» — потому что проверялась только через API, а не глазами.

## Железные правила
1. **Смотреть глазами до отчёта.** Приватный Google-документ открывается только в Chrome Павла
   (`mcp__claude-in-chrome__navigate` → screenshot каждой вкладки). Без скриншота слово «оформлено» не произносить.
2. **Сначала скилл/гайд, потом код.** Опорные гайды: Ben Collins «Making Google Sheets look less like Google Sheets»,
   Bricks «How to make a nice table». Их суть — в разделе «Раскладка».
3. **Подсветка — на ячейке, не на строке.** Правило «= "нет"» на всю строку при 78 таких из 79 даёт розовую стену.
   Строку целиком красить только для действительно срочного (ждёт > часа) и очень бледно (`#FFF5F5`).
4. **Без сырых значений.** `not_ready`, `bankruptcy_route`, `bot` — переводить в человеческие подписи в Python до записи.
5. **Идемпотентность.** Перед каждым прогоном снимать `bandedRanges`, `conditionalFormats`, `unmergeCells`,
   сбрасывать `userEnteredFormat` и `hiddenByUser` — иначе правила копятся с каждым запуском.

## Раскладка, которая работает
- Шрифт `Roboto` 10 везде; гридлайны выключены (`hideGridlines: true`); строки 30px, шапка 40px.
- Лист-таблица: строка 1 — заголовок листа + «обновлено …» (12 bold), строка 2 — тёмная шапка `#111827`
  с белым bold, заморозить 2 строки и 2 колонки, `setBasicFilter` на шапку, зебра `#FFFFFF/#FAFAFA`,
  тонкая нижняя граница строк `#E5E7EB`, padding 8px. Числа вправо с `#,##0`, даты по центру серым `dd.mm.yy`.
- Техническую колонку для сортировки/светофора (минуты) ставить **последней** и скрывать — скрытая колонка
  посреди таблицы рисует «◂▸»-дыру.
- Дашборд-сводка: колонка A = 24px отступ; B = 170, C..I = 112 ровно (никаких узких колонок-разделителей —
  они ломают таблицу ниже). KPI-плитки — объединённые пары колонок, две строки (значение 26 bold, подпись 9 серым),
  фон `#F3F4F6`, белые границы 3px как зазор. Ниже таблица по людям с тёмной шапкой; легенда «Как читать»
  в конце — жирная метка в B, текст объединён C:I.
- Палитра: текст `#111827`, серый `#6B7280`; светофор фон/текст — красный `#FEE2E2/#B91C1C`,
  оранжевый `#FFEDD5/#C2410C`, зелёный `#DCFCE7/#15803D`.
- Ники — `=HYPERLINK("https://t.me/nick";"@nick")`, значения писать через `valueInputOption=USER_ENTERED`.

## Грабли Sheets API
- **ru-локаль:** в `CUSTOM_FORMULA` и HYPERLINK разделитель аргументов `;`, десятичный — `,` (`0,3`, не `0.3`).
  Брать из `spreadsheets.get().properties.locale`. Иначе 400 «Invalid ConditionValue».
- **Приоритет условных правил:** каждое `addConditionalFormatRule` с `index: 0` встаёт выше предыдущих,
  и первое совпавшее правило блокирует остальные. Строчную подсветку добавлять ПЕРВОЙ, ячеечные — после.
- `batchUpdate` атомарен: ошибка в одном запросе откатывает все. Значения (`values.update`) при этом уже записаны.
- Заголовок с иконкой фильтра требует +15px ширины, иначе переносится («Источни/к»).
- Сервис-аккаунт должен быть **writer** на файле; файл создавать от владельца (Drive MCP `create_file`
  с `application/vnd.google-apps.spreadsheet`, потом `share_file` SA как writer) — владелец остаётся человек.
- Ключ и id таблицы: `~/.claude/secrets/google.env` (Mac) и `/opt/wb-refund-bot/secrets/google.env` (VPS).

## Шаблон
`templates/sheets_sync.py` — рабочий скрипт MPZORRO (SQLite → три листа → форматирование).
Копировать и менять `load_rows()` / `HEAD` / `WIDTHS`.

## Реальное время из своей БД (SQLite на VPS)
Google к SQLite не подключится (Connected Sheets — только BigQuery/Looker; Apps Script JDBC — MySQL/Postgres и ≥1 мин;
IMPORTDATA — кэш ~час). Единственный быстрый путь — push из приложения: один лист данных + формулы над ним,
приложение сравнивает подпись базы в отдельном потоке раз в секунду, склейка 5 с, пуш `--data` отдельным процессом
(~2,5 с на 370 строк). Итог ~9 с. Проверка внутри long-polling-цикла бота даёт 30 с — не ставить туда.

## Уроки 11.09 (вторая итерация)
- **Буквы колонок — из заголовка, не руками.** `L("мин")` по `HEAD.index()`; вставка колонки посреди таблицы иначе ломает все QUERY/COUNTIF.
- **Сетка листа по умолчанию 26 колонок.** Ячейка `AB1` даёт 400 «exceeds grid limits». Метку времени класть в строку 1 правее заголовка (`Z1`) или расширять `gridProperties.columnCount`.
- **Проверять семантику полей базы до формул.** `claim_submitted` оказался датой, а не «да»; `entry_fee` — назначенная сумма, а не факт оплаты (оплата = статус `payment_received` и дальше). Один `select distinct` дешевле неверной воронки.
- **Одна метрика — одно определение на все экраны.** «Ждут ответа» в боте (написал текстом) и «42 дела» у Зорро (любая активность после касания) — разные вещи; в таблице теперь обе, с подписью, что есть что.
- **Deep-link из таблицы в бота:** `=HYPERLINK("https://t.me/<bot>?start=dlg_<tg_id>";"💬 в боте")` + обработчик `/start dlg_` только для сотрудников.
- Шапка 112px вмещает ~16 символов bold 10; «Активны без ответа» режется — короткая подпись в шапке, длинная в легенде.
- Скролл в Chrome-MCP на Google Sheets не двигает лист — переходить через поле имени ячейки (`B45` + Enter).
