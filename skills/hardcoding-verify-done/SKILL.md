# Hard Coding · Verify Done

Используй этот Skill, когда нужно решить, можно ли честно сказать «готово».

## Правило
Команда, код или красивый ответ не являются доказательством результата.

## Алгоритм
1. Назови главный пользовательский сценарий.
2. Определи, какое evidence реально подтверждает его.
3. Проверь результат через подходящий источник: тест, readback, HTTP, UI, API, БД, message id, публичный URL или другой фактический сигнал.
4. Если было исправление — повтори тот же тест, который раньше падал.
5. Отдели:
   - что проверено;
   - что не проверено;
   - что осталось сделать человеку.
6. Говори «готово» только если критерий результата выполнен.

## Не делай
- не подменяй E2E компиляцией;
- не считай stdout доказательством внешнего эффекта;
- не выдумывай тесты;
- не повторяй опасную mutation, если исход предыдущей неизвестен.
