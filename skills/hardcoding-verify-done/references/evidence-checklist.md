# Evidence checklist

Выбирай минимальный достаточный набор.

- Файл: повторное чтение нужного участка.
- Git: diff + commit/ref.
- Тест: exit 0 + проверяемый сценарий.
- API: фактический ответ API.
- База: readback нужной записи/схемы.
- Telegram: `message_id` или живое получение.
- Web: HTTP + содержимое страницы, а для UI — реальный render.
- Deploy: deployed commit/version + health/readback.
- Интеграция: полный путь от входа до ожидаемого внешнего результата.

Если evidence получить нельзя, так и напиши: «изменение сделано, но X не проверено».
