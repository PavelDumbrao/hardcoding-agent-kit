## HTML для user-session

```html
🤖 <b>{КРЮЧОК: РЕЗУЛЬТАТ + ЛИЧНЫЙ КОНТЕКСТ}</b>

{ОДИН ПЛОТНЫЙ АБЗАЦ: ЧТО ПРОИЗОШЛО, ЧТО РАЗОБРАНО, ЗАЧЕМ ЧИТАТЬ}

<a href="{TELEGRAPH_URL}">📖 Полный разбор</a>
```

Параметры отправки:

```json
{
  "parse_mode": "html",
  "disable_preview": false,
  "request_id": "unique-id"
}
```

Не добавляй видимый URL после ссылки. В сообщении должна быть одна главная ссылка на Telegraph.
