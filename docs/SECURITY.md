# Security model

Hard Coding Agent Kit снижает риск случайных действий, но не является песочницей уровня ОС.

## Что делает guard

`PreToolUse` блокирует:
- разрушительное `rm -rf` по системным/домашним корням;
- `sudo`;
- локальный `find /`;
- `git add` secret-файлов;
- чтение `.env` / private keys через shell;
- чтение `.env` / private keys через tool `Read`.

## Что guard не обещает

- он не контролирует инструменты, которые runtime не передаёт в hooks;
- он не заменяет permissions самого runtime;
- он не защищает от всех возможных способов эксфильтрации;
- он не должен быть единственным слоем безопасности.

## Секреты

Реальные secrets:
- не передаются в обычный чат;
- не коммитятся;
- вводятся локально через `configure_telegram.py`;
- лежат в `~/.hardcoding-agent-kit/secrets/telegram.env`;
- файл получает права `600`.

Если runtime предоставляет собственный secret store/keychain, его можно использовать вместо env-файла.
