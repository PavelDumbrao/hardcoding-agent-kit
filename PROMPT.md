# 🚀 ПРОМПТ: установка агента одним сообщением

**Это единственный файл, который тебе нужен.** Выдели весь текст в сером блоке ниже,
скопируй и вставь своему ИИ-агенту (ZCode, Claude Code или Codex) одним сообщением.
Дальше агент сам скачает, установит, проведёт тебя по секретам и всё проверит.

Полная теория «что такое скиллы/инструкции/хуки» — в [LESSON-SKILLS-HOOKS.md](LESSON-SKILLS-HOOKS.md).

---

```text
Ты мой ИИ-агент и мой сисадмин. Установи мне набор Hard Coding Agent Kit —
инструкцию, хуки-охрану и Telegram-уведомления. Я не программист, поэтому:
объясняй каждый шаг одним предложением, работай по шагам, после каждого шага
говори «готово, делаем X». Ничего не удаляй, ничего не перезаписывай без
необходимости, секреты в чат не выводи.

ДЕЛАЙ РОВНО ПО ЭТОМУ ПЛАНУ:

ШАГ 1. ОПРЕДЕЛИ РАНТАЙМ.
Если ты работаешь в ZCode (есть папка ~/.zcode) — устанавливаем для ZCode.
Если Claude Code (~/.claude) — для Claude Code. Если Codex (~/.codex) — для Codex.
Скажи мне, что выбрал. Если обнаружено несколько — спроси меня, какой главный.

ШАГ 2. СКАЧАЙ КИТ.
curl -L https://github.com/PavelDumbrao/hardcoding-agent-kit/archive/refs/heads/main.zip -o /tmp/hcak.zip
mkdir -p ~/.hardcoding-agent-kit && unzip -oq /tmp/hcak.zip -d /tmp/hcak
и перенеси содержимое папки hardcoding-agent-kit-main в ~/.hardcoding-agent-kit.
Если curl не сработал — попробуй git clone https://github.com/PavelDumbrao/hardcoding-agent-kit.git ~/.hardcoding-agent-kit

ШАГ 3. ЗАПУСТИ УСТАНОВЩИК.
bash ~/.hardcoding-agent-kit/install.sh
Он скопирует хуки в ~/.zcode/hooks (общая папка скриптов — подходит всем рантаймам),
создаст заготовку секретов и НЕ тронет существующие файлы. Покажи мне его вывод.

ШАГ 4. НАСТРОИМ TELEGRAM (самый важный шаг для меня, веди меня за руку):
4.1. Спроси меня: «Есть ли у тебя Telegram-бот?»
4.2. Если нет — дай мне мини-инструкцию: открыть @BotFather → /newbot → задать имя
     → получить токен вида 123456789:AA... → скопировать его.
4.3. Попроси меня узнать свой chat_id (открыть @userinfobot — он покажет «Id»).
4.4. ДВА способа записать секреты, предложи мне выбрать:
     а) безопасный: открой мне файл командой open -e ~/.zcode/secrets/telegram.env
        и я сам впишу две строки (покажи мне их шаблон);
     б) быстрый: я пришлю токен в чат — ты запишешь его в файл одной командой,
        НО предупреди меня, что после установки токен можно перевыпустить у @BotFather.
4.5. После записи сделай файл приватным: chmod 600 ~/.zcode/secrets/telegram.env
4.6. Проверь доставку: python3 ~/.zcode/hooks/test_notify.py
     Мне в Telegram должно прийти сообщение. Если не пришло — диагностируй
     (токен с пробелом, неверный chat_id, нет интернета) и почини вместе со мной.

ШАГ 5. ПОДКЛЮЧИ ХУКИ В КОНФИГ СВОЕГО РАНТАЙМА.
Возьми блок из ~/.hardcoding-agent-kit/config-examples/config-zcode.json.
- ZCode: файл ~/.zcode/cli/config.json. ЕСЛИ ФАЙЛА НЕТ — создай с блоком из примера.
  ЕСЛИ ЕСТЬ — аккуратно добавь "hooks" внутрь, СОХРАНИВ существующие mcp.servers.
  Критично: события кладутся внутрь "hooks": { "enabled": true, "events": {...} }.
- Claude Code: файл ~/.claude/settings.json — добавь блок "hooks" (без enabled),
  события те же: SessionStart, UserPromptSubmit, PreToolUse (matcher Bash|Write|Edit|MultiEdit),
  PostToolUse, Stop; команды те же: python3 ~/.zcode/hooks/<скрипт>.py
- Codex: файл ~/.codex/hooks.json (создай, если нет) — формат {"hooks": {<Событие>: [...]}}.
- ЕСЛИ у меня уже есть какие-то хуки — не дублируй, спроси, что делать с пересечениями.
Также: если у меня ещё нет глобальной инструкции (~/.zcode/AGENTS.md или
~/.claude/CLAUDE.md) — предложи поставить шаблон AGENTS.md из кита и помоги
заполнить раздел «Мои данные» вопросами: кем работаешь, типовые задачи, проекты.
Если инструкция есть — НЕ перезаписывай, просто покажи, где лежит.

ШАГ 6. ПРИЁМКА.
6.1. Запусти: python3 ~/.zcode/hooks/smoke.py — доложи результат (норма: 24/24 PASS).
6.2. Перезапуск не делай сам — скажи мне перезапустить приложение и открыть новый чат.
6.3. Дай мне финальный отчёт по шаблону:
     - рантайм: <...>
     - хуки: <скопированы/нет, куда>
     - секреты: <записаны/нет>
     - smoke: <.../24>
     - тест Telegram: <пришло/нет>
     - что осталось сделать мне руками: <список>
6.4. Расскажи мне в двух предложениях, что теперь будет происходить само:
     планёрка в начале чата, охрана на опасных командах, звонок в Telegram по завершении.
     И где читать теорию: ~/.hardcoding-agent-kit/LESSON-SKILLS-HOOKS.md

ПРАВИЛА БЕЗОПАСНОСТИ ДЛЯ ТЕБЯ НА ВСЮ ЗАДАЧУ:
- токены и содержимое secrets-файлов в чат не выводи;
- существующие конфиги правь только добавлением, с бэкапом рядом (файл.bak-<дата>);
- если что-то пошло не так — остановись и объясни мне человеческим языком;
- работай по шагам и жди моего «ок» между крупными шагами (после шага 3 и шага 4 — обязательно).
```
